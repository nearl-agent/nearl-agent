Security: how the contracts were checked

NEARL's contracts have not been audited by an outside firm yet. Until they are, this is everything that has been done, so you can judge the risk yourself.

CheckWhat it coversResult
Verified sourceThe deployed bytecode matches the published source (Blockscout and Sourcify)Exact match
Unit testsEarn and Guard: the main rules, permissions and payouts26 passing
Guard fuzz testRandom actions by the owner, the agent and outsiders, with time jumps, checked against Guard's rules after every step0 violations in 24,000 actions (last full run); 2,400 on every test run
Earn solvency testRandom deposits and price paths: the contract can always pay every depositor and the pool creatorPassing
Mainnet fork testThe live mainnet contracts run end to end on a copy of Robinhood Chain: four Earn scenarios and every Guard limit35 checks passing
Slither scanStatic analysis by Trail of Bits' Slither0 high; 15 lower findings reviewed: false alarms or intended
Mythril scanSymbolic execution by ConsenSys' Mythril, a time-limited run (up to 10 minutes per contract)No issues detected

None of this proves the contracts are bug-free. Tests only cover the cases someone thought of, fuzzing tries many but not all combinations, and scanners look for known patterns. It lowers the risk; it does not remove it.

Independent review. An outside security team is reviewing NearlGuard, NearlGuardFactory and NearlNotes at the published commit. This is a review, not an audit. Its findings will be fixed before any pool caps go up, and a summary will be published here once the fixes are live.

Report a vulnerability. Please report security problems privately through GitHub: open the Security tab of the NEARL repository and choose Report a vulnerability. Do not open a public issue for anything that could put funds at risk.

Known limits. No third-party audit yet. Earn does not check Chainlink's sequencer uptime feed (stale prices are still rejected). Earn and Guard support standard ERC-20 tokens only. That is why mainnet amounts stay small and capped.

Verify a contract yourself

  1. Open the address on the Blockscout explorer from the table above.
  2. Go to the Contract tab. A verified contract shows its full Solidity source code.
  3. Compare it with the code in the NEARL repository (contracts/).
  4. Never approve a transaction to an address that is not listed on this page.

Every NEARL contract on mainnet and testnet is verified with an exact source match. Mainnet sources are also published on Sourcify.
