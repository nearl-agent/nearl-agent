The short version

  • No accounts, no sign-up, no email collection.
  • No analytics, advertising or tracking cookies.
  • NEARL never receives your private key or seed phrase.
  • Your wallet address and transactions are public on Robinhood Chain, like every blockchain.

What we collect

The NEARL website is a static site. Almost everything (Check, Guard, Earn) runs in your browser and talks directly to the public Robinhood Chain RPC.

DataWhenWhyKept for
IP address and request detailsWhen you load the websiteStandard web server logs at our host, NetlifyAs set by Netlify
IP addressWhen you call the Check API or MCP serverRate limiting (20 checks per minute)About one minute
A running count of checksWhen a check finishes on the website, the API or the MCP serverThe "checks run" number on the Stats pageOnly the total is kept; no token, IP address or wallet is stored with it
Token address you checked and its resultWhen you call the Check API or MCP serverA short cache so repeat checks are fastAbout two minutes

We do not sell or share this data, and we do not combine it with your wallet address.

Stored on your device

NEARL saves two small preferences in your browser's local storage: which wallet you connected last (so it can reconnect) and which network you picked on the Earn page. Nothing else. Clearing your browser data removes them.

The blockchain is public

When you connect a wallet and send a transaction, your wallet address, the transaction and its amounts are recorded permanently on Robinhood Chain. Anyone can see them, and NEARL pages such as the onchain ledger display them. This is how public blockchains work and cannot be undone.

API and MCP

If you connect an AI agent to the NEARL API or MCP server, the agent sends us the token address it wants checked. We do not receive your prompts, conversations or wallet keys.

Your choices

You can use the Check page without connecting a wallet. You can disconnect your wallet at any time from the NEARL pages or from your wallet's settings. Data written to the blockchain cannot be deleted by anyone.
