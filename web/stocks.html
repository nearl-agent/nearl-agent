How NEARL knows

This list is not typed in by hand. It is read from the blockchain:

  1. Robinhood creates every stock token through one contract, its StockFactory (). Each time, the factory records the new token's address, name and ticker on-chain.
  2. NEARL reads all of those records, then checks that each token runs on Robinhood's stock-token code ().
  3. Only Robinhood can create tokens with that factory. A test call from any other address is refused.

When you check a token on Check, NEARL marks an official stock token as official, and warns you when a token only copies a stock's ticker or name. A stock token newer than this list is confirmed against the factory on the spot.

Good to know. Robinhood describes stock tokens as tracking the share price without giving you ownership of the share itself. Robinhood can upgrade, mint and freeze them, as an issuer would. This page shows which tokens are real; it is not investment advice.
